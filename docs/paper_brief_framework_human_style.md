# 论文思路整理

## 题目

融合层次结构先验与风格条件的中国山水画高保真可控生成方法

英文可写为：

Hierarchical Structure-Guided and Style-Conditioned High-Fidelity Generation for Chinese Landscape Painting

## 研究出发点

中国山水画生成和普通自然图像生成并不是同一个问题。前者更强调章法、留白、远中近景层次，以及整体笔墨气质的一致性。通用文生图模型即使能够生成“像山水”的画面，也常常在结构组织、画面气韵和风格稳定性上存在明显缺陷。仅靠文本提示很难把这些因素同时控制住，单纯做 LoRA 微调虽然能改善领域适配，但仍然不足以解决构图漂移和风格不稳的问题。

这篇论文的核心思路，就是在 SDXL 的基础上，把内容语义、画面结构和风格参考三类信息放进同一个生成框架里，让模型不仅“能生成山水画”，而且尽量生成出结构合理、风格统一、质量稳定的中国山水画图像。

## 方法主线

整体框架可以概括为一句话：以 SDXL 为主干，通过 LoRA 做领域适配，通过层次结构图约束章法组织，再通过风格参考分支增强笔墨风格一致性。

其中，文本条件负责给出内容语义；结构条件负责约束远中近景、线稿和留白布局；风格条件则负责把生成结果往特定的山水画风格上拉近。三者共同作用，目标不是简单增强“像不像山水”，而是提升画面的可控性和完整性。

## 论文真正的创新点

本文最值得强调的创新点，不宜写得太散，建议集中到下面三点。

第一，本文不是直接套用自然图像里的深度图或边缘图，而是构建了一种更适合中国山水画的层次结构表示。这个结构表示由 `lineart`、`quantized_depth`、`blank_space_mask` 和 `salient_composition_mask` 四部分组成，重点不是恢复真实三维场景，而是刻画章法层次、虚实关系和构图重心。这个设计更贴合中国山水画本身的组织规律。

第二，本文不是把任务做成单纯的文本到图像生成，而是做成“文本语义 + 层次结构 + 风格参考”的三条件协同生成。这样做的意义在于，文本负责说清画什么，结构负责说清怎么布，风格负责说清画成什么气质。相比只靠文本或只靠 LoRA 的方法，这种协同建模更容易稳定地得到结构完整、风格统一的结果。

第三，实验部分没有只停留在常见的 `FID` 或 `CLIPScore` 上，而是进一步引入了结构一致性、留白相关指标、风格准确率，以及 `PickScore`、`HPSv2` 这类偏好代理指标。这样做的目的，是让实验评价更接近中国山水画任务本身，而不只是停留在通用图像生成的表层比较。

## 实验应该怎么讲

实验部分建议围绕“主结果、消融、控制、泛化”四条线展开，但写作上不要机械分块，而是让这四部分服务于同一个问题：本文方法为什么有效，以及到底有效在哪里。

主结果部分，最重要的是和 `SDXL + LoRA` 做直接比较，因为它最能说明这套结构先验和风格分支是否真的带来了额外收益。如果版面允许，可以再补一个 `SDXL text-only`，把最基础的文本生成基线也放进来。

当前主结果已经可以支撑一个比较明确的结论。相对于 `SDXL + LoRA`，本文方法在 `FID`、`KID`、`PickScore`、`HPSv2`、`LPIPS diversity` 和 `style accuracy` 上都更好。这说明它不仅在分布保真度上更优，而且在风格一致性、感知偏好和生成多样性上也更有优势。

消融实验部分，重点不在于把所有模块逐个拆掉，而在于说明哪一部分真正解决了哪一个问题。最关键的几组建议保留为：完整模型、去掉结构分支、去掉风格分支、只保留 LoRA，以及不同 prompt 形式之间的比较。结构分支重点看章法和构图控制，风格分支重点看风格准确率和偏好指标，prompt 形式则重点看文本一致性和生成稳定性。

控制实验最好用图像来说话。比如同一个 prompt 下给不同结构图，看画面布局是否真的跟着变；同一个结构图下更换不同风格参考，看笔墨风格是否稳定迁移；同样的内容用 short、structured 和 dense 三种提示形式，看结果差异是否具有规律性。这些图比单纯多放几张样例更有说服力。

如果想让实验更完整，还可以补一点泛化讨论，例如未见组合提示词、诗意提示词、季节变化提示词，以及稀疏构图和复杂构图两类场景。这部分不用写得过重，但可以帮助论文从“有效”走向“更稳健”。

## 当前结果可以怎么包装

从目前已经跑出来的结果看，本文方法相较于 `SDXL + LoRA` 有比较稳定的优势：

- `FID` 从 `261.36` 降到 `164.81`
- `KID` 从 `0.19544` 降到 `0.05868`
- `PickScore` 从 `19.38` 提升到 `19.67`
- `HPSv2` 从 `0.1379` 提升到 `0.1631`
- `LPIPS diversity` 从 `0.3706` 提升到 `0.4747`
- `style accuracy` 从 `0.3373` 提升到 `0.5542`

这组结果比较适合支撑下面这个结论：层次结构先验和风格条件协同建模，不只是让图像“更像中国画”，而是在高保真、风格一致性和可控性之间取得了更好的平衡。

## 正文结构建议

正文结构不需要写得太花，保持传统但扎实即可。

第一部分是引言。这里把问题背景、研究难点、现有方法不足和本文贡献讲清楚，重点突出中国山水画任务与通用文生图任务的差异。

第二部分是相关工作。分成扩散模型、可控生成、风格条件生成、中国画生成四块就够，不需要过度铺陈。

第三部分是方法。先讲整体框架，再分别讲结构化提示词、层次结构图、LoRA 适配、结构控制分支和风格参考分支，最后给出训练与推理过程。

第四部分是实验。先交代数据集、实现细节和评测协议，再讲主结果、消融结果、可视化控制实验和泛化分析。

最后是结论。结论只需要回收到三个点：一是本文方法确实提高了高保真生成质量，二是结构控制确实更稳定，三是风格条件对山水画风格一致性有明显帮助。

## 写作时要避免的表达

这篇论文不建议写成“模型已经达到艺术家水平”，也不要写成“自动指标可以替代人工审美判断”。更稳妥的表述是：本文方法在统一客观评测协议下显著优于现有基线，并在结构保持、风格一致性和高保真生成之间取得了更好的平衡。

如果后面要继续扩写，这份提纲最适合直接发展成三部分：摘要、引言和实验章节。方法部分则可以在这条主线基础上再补公式和模块细节。
