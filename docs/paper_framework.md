# 论文概述

## 题目

**融合层次结构先验与风格条件的中国山水画高保真可控生成方法**

英文：

**Hierarchical Structure-Guided and Style-Conditioned High-Fidelity Generation for Chinese Landscape Painting**

## 核心问题

中国山水画生成存在 3 个关键难点：

- 章法结构难保持，容易出现远中近景混乱
- 留白和构图难控制，画面容易失衡
- 笔墨风格不稳定，生成结果缺少统一风格特征

## 方法概述

本文提出一个三条件协同生成框架：

- 文本条件：结构化提示词
- 结构条件：层次结构图
- 风格条件：参考风格图像

基础模型使用 `SDXL`，并结合：

- `LoRA` 做领域适配
- `Hierarchical Adapter` 做结构控制
- `IP-Adapter` 做风格参考控制

# 创新点

## 创新点 1：面向中国山水画的层次结构先验

构建四通道结构图，不直接套用自然图像控制条件：

- `lineart`
- `quantized_depth`
- `blank_space_mask`
- `salient_composition_mask`

作用：

- 显式建模远中近景层次
- 约束留白区域
- 强化章法结构控制

## 创新点 2：结构、文本、风格三条件协同生成

不是单一文本生成，而是联合建模：

- 内容语义
- 构图结构
- 风格参考

作用：

- 提升生成可控性
- 减少结构漂移
- 提高风格一致性

## 创新点 3：面向中国画任务的客观评测协议

除常规图像生成指标外，补充：

- 结构一致性
- 留白相关指标
- 风格准确率
- 人类偏好代理指标

作用：

- 更贴合中国山水画任务特点
- 实验结论更完整

# 实验重点

## 1. 主对比实验

对比方法：

- `SDXL text-only`
- `SDXL + LoRA`
- `Ours`

主指标：

- `FID`
- `KID`
- `CLIPScore`
- `PickScore`
- `HPSv2`
- `LPIPS diversity`
- `Style accuracy`

## 2. 消融实验


- Full model
- 去掉结构分支
- 去掉风格分支
- 仅 LoRA
- 不同 prompt 形式
- 不同结构通道组合

分析：

- 结构分支是否提升章法控制
- 风格分支是否提升风格一致性
- prompt 形式是否影响生成稳定性

## 3. 控制实验

- 同 prompt，不同结构图
- 同结构图，不同风格参考图
- 同内容，不同 prompt 形式

展示：

- 结构控制能力
- 风格迁移能力
- 生成稳定性

## 4. 泛化实验

建议补充：

- 未见组合提示词
- 诗意提示词
- 季节变化提示词
- 稀疏构图与复杂构图场景

---


## 结论

相较于 `SDXL + LoRA`，本文方法在：

- 保真度上更优
- 风格一致性上更强
- 多样性上更高
- 感知偏好指标上更好

说明层次结构先验和风格参考分支是有效的。
