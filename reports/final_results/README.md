# Final Results Snapshot

This folder contains the publishable experiment snapshot used for the final paper narrative.

Included files:

- `main_results_mean_std.csv`: final main table with `mean +/- std`
- `main_results_raw.csv`: per-run raw quantitative results
- `significance_ours_vs_lora.csv`
- `significance_ours_vs_controlnet.csv`
- `significance_ours_vs_ip_adapter_only.csv`
- `final_results_story.md`: concise interpretation of the final results
- `final_results_story.json`: structured version of the same summary
- `benchmark_summary_v6.json`: public benchmark caveat summary used in the discussion
